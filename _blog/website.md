This site features a custom SVG animation system that creates dynamic, organic curves that constantly evolve and change. The animations are built with JavaScript and SVG, using procedural generation to create unique patterns each time.

## Technical Details

- **Three-column responsive layout** with fixed sidebar and dynamic content
- **Custom SVG wiggle system** with configurable parameters
- **Google Fonts integration** (Syne Mono + Sono)
- **CSS custom properties** for easy theming
- **Modular content system** using markdown files

The right column showcases my creative coding work with these animated SVG curves that respond to window resizing and create a living, breathing digital environment.
